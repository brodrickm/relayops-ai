# RelayOps AI

Dependency-free launch site for RelayOps AI. Deploy the directory directly to Vercel as a static project.

## Positioning

RelayOps AI installs guarded, measurable AI operations for small service businesses. The initial wedge is lead intake through follow-up, with human approval for consequential actions.

## Local preview

Open `index.html` in a browser. No build step is required.

## Launch gate

Before public promotion, replace the email CTA if needed and approve the final offer, pricing, privacy notice, and terms.
